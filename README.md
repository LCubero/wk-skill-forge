# wk-skill-forge

Home repository for the `wk-skill-forge` skill: a global, command-only skill to Create, Audit, Improve, and Evaluate LLM-first agent skills that run alone under any CLI agent.

## Purpose

- One repository, one skill. The skill folder name and its frontmatter `name` are both `wk-skill-forge`.
- The skill is global: the owner copies it to the global skills folders. This repository develops it; it does not install or distribute it.
- Naming convention for the owner's skills: `wk-<name>`, lowercase with hyphens, no `-ld9` suffix. Ownership is shown by the `wk` prefix and the frontmatter `author`.

## How this repository starts

The skill is being recreated stage by stage from its first version, following the [roadmap](docs/repo-harness/roadmap.md). The owner decides how far each session advances. Each stage may also improve on the original.

The original was developed as `wk-skill-forge-ld9` in `<original-repo>`, a local clone of the original repository (`0_skill/mis_skills/wk-skill-forge-ld9/`). That repository is a read-only reference: read its commits, never edit it from here.
